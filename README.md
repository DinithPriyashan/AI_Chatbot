# JARVIS AI Assistant

A browser-based voice chatbot built with HTML, TailwindCSS, JavaScript, and the Web Speech API.

## Live app

- **HTTPS:** https://dinithpriyashan.github.io/AI_Chatbot/

GitHub Pages serves the app over HTTPS. Microphone access requires HTTPS or localhost.

## Features

- Voice-controlled commands
- Quick website access
- Gemini API integration
- Responsive dark-mode interface

## Run locally

```bash
python -m http.server 8000
```

Open `http://localhost:8000/`.

For AI responses, add a Gemini API key through a secure backend. Do not expose a production API key in browser JavaScript.
